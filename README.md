# Go Practice

Go Practiceは、KataGoとの対局と棋譜の検討を1つの画面で行うローカルアプリです。初心者向けに強さを調整したAIと対局し、対局中の局面に戻ってKataGoの評価を調べたり、別の手順を試したりできます。SGFとJSONの棋譜を読み込めるほか、MCPに対応するAI agentに表示中の局面を共有できます。
