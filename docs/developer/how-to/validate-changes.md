# テストと静的検査の実行

リポジトリのルートでコマンドを実行する。依存関係の導入と開発用サーバーの起動は[開発環境での対局作成](../tutorials/first-local-game.md)を参照する。

Goとフロントエンドのテスト、静的検査、書式検査、型検査をまとめて実行する。

```sh
make check
```

対象を絞る場合は[開発コマンド](../reference/commands.md#テストと静的検査)から選ぶ。CIではこれらの検査に加え、本番用フロントエンドをビルドする。CIのフロントエンドテストは、対局の既定名を確認するテストが日本時間を前提とするため、`TZ=Asia/Tokyo`で実行する。
