# 対局の保存と復元

## 保存単位

データディレクトリには、対局IDに`.json`を付けたファイルを対局ごとに置く。棋譜や対局設定に加え、 "現在の局面" と局面の解析結果も保存する。保存した対局の一覧の並び順は別のファイルに記録する。

## 保存の確定

対局を保存する前に、読み込み時と同じ検証を適用し、SGFとJSONの書き出し上限も確認する。保存時はデータディレクトリ内の一時ファイルに内容を書き込み、同期してから保存先のファイルと置き換える。置き換え後のディレクトリの同期に失敗した場合は、直前のファイルへの復元を試みる。

着手や変化の編集では、対局に変更を適用し、保存が完了してから成功を返す。保存に失敗した場合は、サーバー内の対局を変更前の状態に戻す。例えば、変化を追加した結果が保存の上限を超えると、操作を拒否し、変更前の棋譜を保持する。

## 起動時の復元

起動時に各対局のファイルを検証し、読み込める対局を復元する。読み込めなかったファイルはそのまま残し、ファイル名と理由をブラウザとMCPから確認できるようにする。一覧の並び順を読み込めない場合は、保存済みの並び替えを適用せずに起動し、次に並び順を保存するときにファイルを書き直す。
