# 局面の同期と操作の競合

## "現在の局面" と "表示中の局面"

"現在の局面" は、対局ごとに持つ棋譜上の位置である。着手や局面移動の基準となり、対局データに保存する。例えば、分析中に棋譜をさかのぼると、 "現在の局面" は選んだ位置へ移り、主分岐の末端は元の位置に残る。

"表示中の局面" は、ブラウザから通知を受けたGoサーバーが保持する対局と局面の組である。サーバー全体で1つだけ保持し、ディスクには保存しない。MCPの`get_selected_position`はこの組を取得する。`select_position`で別の局面を選ぶと、その対局の "現在の局面" も移動する。

## 編集中の競合

ブラウザは、対局名の編集中や変化の削除確認中などに、操作の種類と対象をサーバーへ通知する。通知された操作と競合するMCPからの変更は、HTTP `409`で拒否する。例えば、変化の削除を確認している間に、その手順をMCPから変更すると、画面で確認した範囲と実際の削除範囲が食い違う可能性がある。

ブラウザは操作中に30秒間隔で通知を更新し、終了時には解除を通知する。ブラウザを閉じるなどして解除の通知が届かない場合も、サーバー側で最後の通知から2分で失効する。

対局名や局面のメモの更新では、変更前に取得した値を要求に含める。変化の削除では、確認した削除対象の局面IDを要求に含める。サーバーは現在の状態と照合し、別の操作による変更を上書きしたり、確認していない局面を削除したりする要求を拒否する。
