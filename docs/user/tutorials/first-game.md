# 初めての対局と分析

9路盤でKataGoと対局し、最初の着手に戻って、別の手を試します。対局と分析を切り替えると、同じ棋譜の上でAIと打つことも、自分で変化を並べることもできます。

## 起動

[配布版の起動手順](../how-to/start-app.md)に沿ってGo Practiceを起動し、対局画面を開きます。

## 最初の着手

「新しい対局」を開き、9路盤、黒番、AIレベル1を選びます。置石なしで対局を始め、盤の中央に黒石を置きます。しばらくすると、AIが打った白石が盤面に加わります。

## 別の手順

「棋譜・変化」で最初に打った黒の着手を選びます。白の応手が盤面から消え、画面は分析モードに切り替わります。盤面の右側で白の候補手を確認し、実戦とは異なる候補手をダブルクリックします。「棋譜・変化」に白の応手が枝分かれして表示され、元の応手と追加した応手を選び直せます。
