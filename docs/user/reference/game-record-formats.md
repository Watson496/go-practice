# 棋譜形式と保存の上限

## SGFの対応範囲

SGFはFF[4]に対応し、1つの正方形の囲碁棋譜だけを読み込みます。`FF`を省略すると規格上はFF[1]になるため、`FF[4]`を明示した棋譜を読み込みます。盤サイズは5、6、7、9、13、19路盤、文字コードはUTF-8、中国式の面積計算に対応します。非ASCII文字を含む棋譜では`CA[UTF-8]`も明示する必要があります。

`RU`と`KM`を省略した棋譜も読み込めます。省略した値は書き出しでも追加せず、内部では中国式の面積計算と、互先7.5目・置き碁0.5目の既定値を使います。コミは-100目以上100目以下の0.5目単位で指定します。初期配置の石を取り除く`AE`には対応しません。読み込んだ`AP`は置き換えません。

主分岐、変化、初期配置、対局者、結果、コメント、未知のプロパティを保持します。目数（持碁を含む）と投了は意味を対局へ反映し、それ以外の結果は値をそのまま記録します。

対局日`DT`は、前後のSGFの空白を除いて日付として検査し、複数の日付がある場合は先頭を使います。読み込んだ値は空白を含めて保持し、書き出しでも同じ値を使います。先頭の日付がISO 8601の`YYYY-MM-DD`、`YYYY-MM`、`YYYY`のいずれかであれば、対局一覧の開始日に使います。対応していない値は、読み込みを中止して理由を表示します。`DT`がない棋譜は、開始日時を不明とし、書き出しでも`DT`を書きません。

開始日時が不明の対局は、対局一覧では読み込んだ時刻の位置に並びます。対局名`GN`もない場合は、読み込んだ時刻から`YYMMDD-HHMM読込`という対局名を付けます。

SGFにはAIレベルとあなたの石の色がないため、読み込んだ対局ではどちらも未設定になります。JSONを読み込む場合は、開始日時と`DT`、対局名と`GN`がそれぞれ一致することも確認します。

## 文章とプロパティの正規化

対局名にはSGFの`GN`を使い、画面で名前を変更した場合も同じプロパティの位置へ反映します。空の`GN`は対局名として保持せず、値の前後にあるSGFの空白も取り除きます。SGFの文章型ではCRLF、LFCR、CRをLFへそろえ、単行文章型では改行を空白へ変えます。タブ、垂直タブ、改ページは半角空白へ変えます。全角空白とNBSPはSGFの空白ではないため、そのまま保持します。JSONから読み込む対局名、変化名、SGFプロパティにも同じ正規化を適用します。未知のプロパティでも、SGFの規則に従って改行、ソフト改行、エスケープを解釈します。そのため、読み込んだ文字列の改行コードやエスケープ表現は、同じ意味の正規形で書き出されます。

SGFは、意味を変えない範囲で正規形へ書き出します。例えば、`KM[+6.5]`は`KM[6.5]`、圧縮した点の範囲は個別の点、盤サイズに応じた旧式のパス表現は空の着手として書き出します。省略時の既定値を内部で使う`SZ`、明示された開始手番や置き碁の情報は、読み込んだ指定の有無を保ちます。

## 結果の扱い

二連続パスで終わる手順に目数の結果がある場合は、`TB`と`TW`があれば、その範囲にある相手の石を死石として扱います。地の範囲がなければ、KataGoのownershipを使って死石を決めます。死石を取り除いて数えた結果と`RE`が一致する場合だけ、棋譜を読み込みます。

目数（持碁を含む）と投了は、勝者や目差などの意味を対局へ反映します。それ以外の結果は、`RE`の値を解釈せずに記録して、対局を終局として扱います。例えば、`RE[W+T]`、`RE[W+F]`、`RE[W+]`、`RE[Void]`、`RE[?]`は、画面ではいずれも「終局」と表示し、SGFへ元の値をそのまま書き出します。

主分岐の末端では主分岐の結果を表示し、それ以外では現在の局面に記録された結果を表示します。終局後に着手が続く棋譜は、終局した手順と続行した手順を変化として区別し、再度書き出しても両方を保持します。

点数の内訳では、黒と白について盤上の石と地を数え、白の点数にコミを加えます。負のコミでは、両方の点数にコミの絶対値を加え、どちらの点数も負にならないようにします。

## 未知のSGFプロパティ

Go Practiceが意味を扱わないSGFプロパティは、識別子が`GP`で始まる場合も含め、ほかの未知のプロパティと同じように保持します。書き出しでは、読み込んだ局面と値を保ったまま出力します。文章型の空白やエスケープなど、SGFの規則で正規化される表現は、同じ意味の正規形になります。

Go Practiceが新しく記録する情報には、SGF FF[4]の標準プロパティだけを使います。「重要な局面」は`HO`、死石を取り除いて数えた地の範囲は`TB`と`TW`、開始日は`DT`へ記録します。AIレベル、あなたの石の色、正確な開始時刻など、標準プロパティで表せない情報を含める場合はJSONを使用します。

## 入力と保存の上限

メモは4000文字以下、対局名と変化名は80文字以下を受け付け、上限を超えた入力は保存や読み込みを拒否します。読み込むSGFとJSON、および書き出すSGFとJSONは10MiB以下です。棋譜には開始局面を含めて4096局面まで記録でき、変化の入れ子も4096段まで受け付けます。操作後のSGFまたはJSONが上限を超える場合は、その操作を保存せずに拒否します。AIレベルやあなたの石の色など、SGFに書き出さない情報も含めて保存する場合は、JSONを使用します。
