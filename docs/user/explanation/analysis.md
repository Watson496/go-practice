# KataGoの評価とAIの応手

## 評価の視点

盤面の右側には、現在の局面に対するKataGoの解析結果が表示されます。局面全体の評価欄と推移グラフは、黒から見た目差と勝率を示します。候補手ごとの勝率と目差は、その局面の手番側から見た値です。visitsと読み筋も候補手ごとに確認できます。盤上の「候補手」は候補の位置を示し、ownershipは各交点が黒・白のどちらに支配されそうかを色で示します。



例えば、局面全体の目差が黒に有利でも、その局面が白の手番なら、候補手の目差を読む基準は白です。対局の流れを追うときは推移グラフを使い、同じ局面の候補を比べるときは候補手の欄を使います。

## AIレベルと候補手

AIレベルを変えると、KataGoの探索量と、候補から応手を選ぶ方法が変わります。低いレベルではKataGoの第1候補以外も選びますが、石を取る手、アタリから逃げる手、直前の応酬など、局面に直接関係する手を考慮します。
