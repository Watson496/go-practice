# 保存した対局の再開

画面左側の「保存した対局」から、再開する対局を選びます。

対局は着手、局面移動、メモの更新など、状態を変える操作ごとに既定の保存先である`data/games`へ保存されます。局面の解析結果も同じ保存データに記録します。`--data-dir`を指定した場合は、その保存先を使用します。ブラウザやサーバーを再起動した後も、画面左側の「保存した対局」から再開できます。

起動時に読み込めない保存ファイルがあっても、そのほかの対局は読み込みます。読み込めなかったファイル名と理由は画面に表示し、MCPの`list_storage_errors`からも取得できます。読み込めなかったファイルはそのまま残ります。
